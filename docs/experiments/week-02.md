# Week 2 experiment · Linear and nonlinear review scores

This is a controlled teaching example for [Week 2](../weeks/week-02.md). It tests whether a small network can learn a rule based on an interaction between two features.

## Protocol

**Hypothesis:** A two-layer ReLU network will achieve lower validation binary cross-entropy than a linear sigmoid classifier when the synthetic target is an XOR-like sign disagreement.

| Element | Specification |
|---|---|
| Data | 512 synthetic observations in timestamp-index order, generated by NumPy’s random generator with seed 2026. Features are independent uniform draws on $[-1,1]$. The target is opposite signs with 5% independent label flips. |
| Split | First 256 for training, next 128 for validation, last 128 reserved and unused. The sizes keep the example cheap and provide a modest validation block. They do not support claims about markets or human behavior. |
| Baseline and comparison | Logistic classifier on the two raw features versus a two-layer network with eight ReLU units. Both use mean binary cross-entropy and the same 450 full-batch updates at learning rate 0.3. Parameter counts and initializations differ. |
| Metrics | Mean training and validation binary cross-entropy, validation accuracy at logit threshold zero, and maximum absolute gradient-check error across all parameter blocks. |
| Reproduction | Run the [notebook](../downloads/week-02_backpropagation.ipynb) from top to bottom. Retain the curves and inspect at least one validation miss. |

## Observed NumPy results

Python 3.11.18, NumPy 2.4.6, and Matplotlib 3.11.2. The largest absolute gradient difference was approximately $9.27\times10^{-12}$ using a centered difference step of $10^{-5}$ away from the ReLU kink.

| Model | Starting train BCE | Final train BCE | Final validation BCE | Final validation accuracy |
|---|---:|---:|---:|---:|
| Linear logistic | 0.6931 | 0.6918 | 0.6899 | 45.3% |
| Two-layer NumPy | 0.6762 | 0.2556 | 0.2784 | 93.0% |

The nonlinear model fit this interaction better under the selected protocol. This is a single seed and a single synthetic path. Validation accuracy is descriptive and depends on the threshold. The split is chronological by generated index, so it cannot demonstrate robustness to actual regime changes or issuer dependence. The PyTorch comparison was skipped in the verified run because the environment lacked PyTorch.

**Follow-up:** Give the linear model an explicit product feature. Decide how to handle feature scaling and whether to tune its optimizer before comparing it with the network. For a real research screen, define priority labels independently and compare missed priority cases at the same review budget on a later, issuer-aware test block.
