# Glossary

| Term | Definition |
|---|---|
| Token | Unit of text processed by a model |
| Embedding | Numeric representation |
| Attention | Weighted aggregation of values |
| KV cache | Stored keys and values used in decoding |
| RAG | Retrieval-augmented generation |
| LoRA | Low-rank adaptation |
| Harness | Software controlling model tools and state |
