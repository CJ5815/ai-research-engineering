# Knowledge, memory and context

Cosine similarity is $s(u,v)=u^\top v/(\|u\|\|v\|)$. Retrieval selects candidate evidence; reranking and context assembly decide what reaches the model. Evaluate recall separately from answer faithfulness. See [RAG](../papers/rag.md), [Lost in the Middle](../papers/lost-middle.md) and [GraphRAG](../papers/graphrag.md).

## Study exercise

Derive the central equation or algorithm, implement a minimal baseline, and record a test that could falsify your hypothesis.
