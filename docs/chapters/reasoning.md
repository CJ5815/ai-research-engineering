# Reasoning and agents

A bounded agent selects tools using current state, validates arguments, observes results and updates the state. Stop after success, a budget limit or an unrecoverable error. Use independent checks rather than treating generated reasoning as proof. See [CoT](../papers/cot.md) and [ReAct](../papers/react.md).

## Study exercise

Derive the central equation or algorithm, implement a minimal baseline, and record a test that could falsify your hypothesis.
