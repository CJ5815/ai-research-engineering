# AI Research & Engineering

*From neural networks to intelligent agents.*

A research-oriented learning hub connecting mathematical foundations, papers, Python experiments and AI systems engineering. Start with the [research roadmap](roadmap.md), browse the [paper library](papers/index.md), or work through the [curriculum](curriculum.md).

## Four pillars

| Pillar | Topics |
|---|---|
| Model science | Neural networks, attention, Transformers, LoRA |
| Knowledge and memory | RAG, context engineering, GraphRAG |
| Reasoning and decisions | Chain-of-Thought, ReAct, feedback loops |
| Systems engineering | KV caching, PagedAttention, evaluation |

## How to study

Read the primary paper, derive the mathematics, implement a small example, then test against a baseline. Record failures as well as successes.
